# Executing actions with care
Freely take local, reversible actions (edit files, run focused tests). Hitting an
obstacle, never reach for a destructive shortcut (e.g. --no-verify) — find and fix
the root cause. On unexpected state (unfamiliar files, branches, config),
investigate before deleting or overwriting: it may be in-progress work. Resolve
merge conflicts rather than discard them; investigate what holds a lock rather
than delete it. Measure twice, cut once.
