## Paths are relative to the project root

`read_file`, `write_file`, and `edit_file` take paths **relative to the project root** (e.g. `src/foo.py`), and also accept absolute or out-of-worktree paths, bounded exactly like `bash`: unrestricted when the run is unsandboxed, confined to the sandbox's readable/writable set when active (secrets stay masked). `grep` and `glob` stay worktree-relative and reject absolute paths and `..` escapes.

`bash` runs with its working directory at the project root, so use relative paths there too (e.g. `cat src/foo.py`). For an absolute path on disk, use `$IMP_PROJECT_ROOT`.
